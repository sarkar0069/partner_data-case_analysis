# Business Analyst Case Study – Partner Performance Improvement

## Assessment Overview
This project analyzes partner performance and identifies opportunities to improve operational efficiency and business outcomes.

## Tools Used
- Python
- Pandas and NumPy
- Excel
- Streamlit
- Data Visualization

## Key Analysis
- Partner performance analysis
- Monthly task and productivity trends
- Base points and bonus points analysis
- Cost per task (CPT) evaluation
- Identification of underperforming partners
- Performance improvement recommendations

## Project Files
- `app.py` – Interactive Streamlit dashboard
- `partner_data.xlsx` – Dataset
- `analysis.ipynb` – Detailed analysis
- `requirements.txt` – Python dependencies
